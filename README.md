## Цели и Задачи ##
Цель - Создать Telegram-бота для быстрой проверки и автоматического исправления ошибок в JSON-файлах, чтобы упростить работу с логами и данными API без использования сложных IDE;

Задача:

1.Изучить спецификацию: Выявить самые частые ошибки, которые люди допускают при написании JSON (одинарные кавычки, висячие запятые, лишние символы).

2.Разработать логику: Написать код бота, который принимает текст, находит ошибки и пытается починить синтаксис автоматически.

3.Протестировать: Проверить работу бота на разные сложности JSON-текста

4.Улучшить UX: Сделать так, чтобы бот выдавал понятный ответ - либо точное указание на строку с фатальной ошибкой.

Этот бот при получении JSON:
* Проверяет навалидность;
* Находит синтаксические ошибки;
* Автоматически восстанавливает структуру данных;

## 💻 Технологии

* Python 3 — язык разработки.
* pyTelegramBotAPI (telebot) — фреймворк для создания Telegram-ботов.
* json — стандартная библиотека Python для валидации и форматирования JSON.
* json_repair — библиотека для автоматического восстановления синтаксически неверного JSON.
* json5 — библиотека для парсинга JSON с расширенным синтаксисом (на случай сложных ошибок).
